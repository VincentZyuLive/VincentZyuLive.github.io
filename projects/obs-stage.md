# 🌊 OBS Stage

OBS Stage 负责水色雾蓝舞台背景、圆角内容槽、前景装饰、头像徽章和 OBS WebSocket 自动化。

## ✨ 核心能力

- `no-screen`、`half-screen`、`full-screen` 三套独立布局
- 1600×900 原生 16:9 设计坐标
- 静态背景 PNG + 轻动态 Browser Source 前景
- 可编辑调色板、圆角、辉光、粒子、字体和头像
- 可选 OBS WebSocket：真实截图、当前场景套用、全部场景套用
- 只管理 `Stage BG` 和 `Stage Frame`，不移动现有内容源
